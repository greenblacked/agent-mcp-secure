# Security Policy

## Reporting a vulnerability

If you discover a security issue in this repository (for example, a check that can be bypassed in a way that creates false confidence, or an example that demonstrates an unsafe pattern without clear warning), please open a private security advisory on GitHub rather than a public issue.

Include:

- A description of the issue
- Steps to reproduce or demonstrate impact
- Any suggested mitigation

This is a personal open-source project. There is no formal SLA. I will review reports as time permits.

## Scope

This policy covers the content of this repository (checks, patterns, examples, and documentation). It does not cover vulnerabilities in third-party MCP servers, agents, or models that users may analyze with these tools.
